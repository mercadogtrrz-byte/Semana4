# Semana 4 - tipos_operandos_rust

## Descripción

Este proyecto fue desarrollado utilizando el lenguaje de programación Rust.

El programa realiza diferentes operaciones utilizando tipos de datos enteros y funciones para representar cálculos relacionados con oleadas y daño.

## Funciones

### calcular_oleadas

Calcula la cantidad de oleadas:

total de enemigos / enemigos por oleada

### calcular_dano_critico

Calcula el daño crítico:

daño base × multiplicador

### calcular_dano_promedio

Calcula el daño promedio:

daño base / número de oleadas
